# Placement Intelligence Lab — *Predict • Analyze • Empower*

**Statistical Modeling of Student Placement Outcomes Using Academic and Socioeconomic Factors**

Executed by Theju Gangadhar and Karthik TG.

A Streamlit platform for statistical modeling and machine-learning analysis of student placement outcomes.

> ## Read this first: data status
> No real student dataset was supplied with this build, so the project ships with a **clearly labelled SYNTHETIC demo dataset**
> (`data/sample/synthetic_placement_demo.csv`, generated by `src/data/loader.py`). Its relationships — including the
> socioeconomic effects — are **developer assumptions**. Metrics shown on this data are **not** real-world validation.
> To use real data, put a CSV in `data/raw/` and run `python train_model.py` (see *Using your own data*).

## Quick start (Windows PowerShell)

Supported Python: **3.10 – 3.13** (developed and tested on 3.13).

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python train_model.py
python -m streamlit run app.py
```

macOS / Linux: `python3 -m venv .venv && source .venv/bin/activate`, then the same `pip` / `python` commands.

Run tests: `python -m pytest -q`

Optional extras (XGBoost, LightGBM, CatBoost, MLflow): `pip install -r requirements-optional.txt`, then retrain.
They are detected automatically; the app runs fully without them.

## Using your own data

1. Copy your CSV into `data/raw/` (the first `*.csv` found is used; real data takes priority over the synthetic sample).
2. The target column is auto-detected from: `placed, placement, placement_status, status, is_placed, placement_outcome, hired`.
   Values must be Placed/Not Placed, Yes/No or 1/0. Otherwise add `data/raw/column_map.json`:
   ```json
   {"target": "my_target_column", "rename": {"old_name": "new_name"}}
   ```
3. Feature types are inferred from the data. Nothing is invented: if your CSV has no socioeconomic columns, the app says so.
4. Columns named `gender, sex, caste, religion, disability, category, community, ethnicity, race, marital_status` are
   **never used as predictors**; they are kept for the fairness audit only. ID-like columns are dropped automatically.
5. Run `python train_model.py --fresh` (or *Settings → Retrain*).

## How it works (short)

* **Leakage control:** preprocessing lives inside scikit-learn Pipelines; model selection uses 5-fold CV ROC-AUC on the training split only; the stratified 80/20 test split is touched once for reporting.
* **Models:** Logistic Regression, Random Forest, Extra Trees, Gradient Boosting, HistGradientBoosting, SVM, Decision Tree (+ XGBoost / LightGBM / CatBoost if installed).
* **Calibration:** the selected model is wrapped in sigmoid `CalibratedClassifierCV` (5-fold, training split). The "range" shown on Predict is the spread across those fold models — an empirical spread, **not** a formal confidence interval.
* **Explainability:** real SHAP (permutation explainer on the transformed matrix, one-hot columns summed back to original features). If SHAP is unavailable the app falls back to permutation importance / occlusion and labels the method explicitly.
* **Statistics:** Welch t / Mann–Whitney, chi-square / Fisher, Cohen's d / rank-biserial / Cramér's V, Benjamini–Hochberg FDR, Wilson intervals, multivariable logistic regression.

## Known limitations

* Synthetic demo data (see top); no external validation on real students.
* UI is an original implementation inspired by the described dark-neon dashboard; the reference image itself was not available to this build, so it is **not** a pixel-level match.
* XGBoost, LightGBM, CatBoost, MLflow and Evidently were not installable in the build sandbox, so their code paths are **untested**. MLflow mirroring is optional; the JSONL log always works. Evidently is not used (statistical fallback only).
* The "3D education" hero is a Plotly 3D concept network (no Three.js).
* Monitoring works on uploaded files only; no live system is connected.
* Not for employment, admission or any individual decision-making on its own.
